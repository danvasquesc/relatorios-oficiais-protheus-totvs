# Relatórios Oficiais - TOTVS Protheus

## Sobre o repositório

Este repositório tem como objetivo centralizar e organizar os códigos-fonte dos relatórios oficiais do TOTVS Protheus, funcionando como uma biblioteca de consulta técnica.

## Objetivo

- Centralizar os códigos-fonte em um único local.
- Facilitar a localização e consulta dos relatórios.
- Organizar os arquivos por módulo do Protheus.
- Manter o histórico e versionamento dos arquivos.

## Organização

Os arquivos estão distribuídos conforme os módulos do TOTVS Protheus:

- Construção e Projetos
- Controladoria
- Financeiro
- Gestão de Serviços
- Logística
- Manufatura
- Manutenção de Ativos
- Materiais
- Qualidade
- Recursos Humanos
- Vendas

Também são armazenados arquivos de inclusão (Includes) e recursos de tradução relacionados aos fontes.

## Ferramentas utilizadas

- TOTVS Protheus
- AdvPL
- Visual Studio Code (VS Code)
- Git
- GitHub

## Origem dos arquivos

Os códigos-fonte foram obtidos diretamente do Portal de Suporte da TOTVS:

[Portal TOTVS - Downloads](https://suporte.totvs.com/portal/p/10098/customer-portal-dashboard/services/downloads)

## Considerações

Este repositório possui finalidade exclusivamente organizacional e de consulta técnica, não sendo destinado à compilação ou execução dos códigos-fonte.

Os direitos sobre os códigos-fonte originais pertencem aos seus respectivos titulares, devendo ser respeitados os termos de licenciamento da TOTVS.
